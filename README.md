# 📸 Nexora Studio

> Capturing Moments. Preserving Memories.

Nexora Studio is a modern wedding photography portfolio website developed using **Next.js** and **Node.js**. The platform showcases photography services, featured love stories, AI-assisted customer support, and an elegant booking experience through a responsive and user-friendly interface.

---

## ✨ Project Highlights

- 🎨 Modern and elegant UI
- 💍 Wedding photography portfolio
- 📖 Featured love stories
- 📷 Photography packages
- 🤖 AI Assistant for customer guidance
- 📅 Easy booking interface
- 📱 Fully responsive design
- ⚡ Fast performance with Next.js

---

## 🛠 Tech Stack

- Next.js
- Node.js
- TypeScript
- CSS
- App Router

> **Frontend Only** (No backend, database, or authentication)

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/dharshiniyadav06-rtyd/nexora.git
```

### Navigate to the project

```bash
cd nexora
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:3000
```
