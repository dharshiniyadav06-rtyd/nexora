# Nexora Studio

A frontend-only wedding photography portfolio website developed using Next.js.

## Requirements

- Node.js (v18 or later)
- npm

## Installation

```bash
npm install
```

## Run the Project

```bash
npm run dev
```

Open your browser:

```
http://localhost:3000
```

## Technology

- Next.js
- Node.js

## Features

- Wedding Portfolio
- Featured Stories
- Photography Packages
- AI Assistant
- Booking Interface
- Responsive Design
